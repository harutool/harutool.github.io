AI 대화 내보내기 - PDF 마크다운 저장 개인정보처리방침

시행일: 2026년 11월 26일

1. 처리하는 정보

이 확장 프로그램은 사용자가 확장 아이콘을 눌러 기능을 쓸 때 chatgpt.com, gemini.google.com, claude.ai에 열려 있는 현재 대화 화면의 글을 읽어 PDF, Markdown, TXT, JSON 파일로 만듭니다. 이 처리는 모두 사용자의 브라우저 안에서 이루어지며, 대화 내용을 개발자 서버나 제3자에게 보내지 않습니다.

2. 저장하는 정보

사용자가 "보관함에 저장"을 누른 대화의 제목, 주소, 폴더, 태그, 대화 텍스트와 오늘 내보내기 횟수, Pro 사용 여부를 브라우저 저장소(chrome.storage.local)에만 저장합니다. 보관함 항목은 사용자가 언제든 지울 수 있고, 확장 프로그램을 삭제하면 모두 삭제됩니다.

3. 외부 전송

유일한 외부 통신은 사용자가 Pro 라이선스 키를 입력하고 "키 확인"을 누를 때 키가 유효한지 확인하기 위해 결제 대행사 Gumroad의 라이선스 확인 API(api.gumroad.com)에 상품 ID와 라이선스 키를 보내는 것입니다. 대화 내용은 이때도 보내지 않습니다. 분석 도구, 광고, 추적 쿠키를 쓰지 않습니다.

4. 권한

storage(보관함 저장), activeTab과 scripting(현재 탭의 대화 읽기), 대화 서비스 3곳과 api.gumroad.com 호스트 권한만 사용합니다.

5. 관계 고지

이 확장 프로그램은 OpenAI, Google, Anthropic과 관계없는 독립 도구입니다.
