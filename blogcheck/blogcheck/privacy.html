블로그 글점검 - 네이버 블로그 글자수, 키워드 개인정보처리방침

시행일: 2026년 11월 26일

1. 수집하는 정보

블로그 글점검은 개인정보를 수집하지 않습니다. 사용자가 네이버 블로그(blog.naver.com) 글쓰기 또는 글 보기 화면에서 점검을 실행하면, 화면에 표시된 제목과 본문 텍스트, 이미지와 링크 개수를 브라우저 안에서 읽어 글자수와 키워드 횟수를 계산합니다. 이 내용은 저장하거나 전송하지 않습니다.

2. 저장하는 정보

사용자가 직접 입력한 목표 키워드와 주의 단어 목록만 브라우저 저장소(chrome.storage.local)에 저장합니다. 확장 프로그램을 삭제하면 함께 삭제됩니다.

3. 외부 전송

어떤 정보도 개발자 서버나 제3자에게 전송하지 않습니다. 분석 도구, 광고, 쿠키를 쓰지 않습니다. 네이버 로그인 정보와 비공개 글 목록은 읽지 않습니다.

4. 기타

블로그 글점검은 네이버의 공식 프로그램이 아니며 네이버와 제휴 관계가 없습니다. 점검 기준은 일반적인 참고값이며 네이버 검색 노출을 보장하지 않습니다.
